## 🌟 Características de la Nueva Plataforma

* 📱 **Diseño 100% Responsivo y Pantalla Completa:** Experiencia inmersiva en computadoras de escritorio, laptops, tablets y smartphones.
* ⚡ **Arquitectura Multi-Página Profesional:**
  * `index.html`: Portada principal con carrusel de bienvenida, métricas de impacto, himno institucional, noticias y mapa interactivo.
  * `nosotros.html`: Historia detallada desde 1962, biografía del ilustre patrono, valores, misión, visión y símbolos escolares.
  * `propuesta-pedagogica.html`: Enfoque por competencias (CNEB), áreas curriculares, tutoría TOE y modalidad CEBA.
  * `talleres.html`: Talleres extracurriculares, club de robótica y ciencias, banda escolar, deportes (JEDPA) y folclore.
  * `admision.html`: Proceso de matrícula, traslados, requisitos, calendario escolar y formulario interactivo de orientación.
  * `contacto.html`: Mesa de partes virtual, teléfonos, canales oficiales, horarios de atención y mapa Google Maps full-width.
* 📍 **Geolocalización con Google Maps:** Integración de mapa interactivo embebido con la ubicación exacta en Mala, Cañete.
* 💬 **Integración WhatsApp Directo:** Botón flotante para comunicación directa con la administración educativa.
* 🎨 **Identidad Visual Oficial:** Escudo vectorial heráldico SVG de alta resolución con laureles, antorcha del saber y lema oficial.

## 🛠️ Tecnologías Empleadas

* **HTML5 Semántico:** Estructura limpia y accesible para motores de búsqueda (SEO).
* **Tailwind CSS & CSS3 Avanzado:** Paleta corporativa institucional (Azul Marino Imperial `#0f2942`, Dorado Heroico `#f59e0b`), degradados modernos y microinteracciones fluidas.
* **JavaScript Moderno (ES6+):** Menú móvil tipo drawer, filtros dinámicos, modales interactivos y scroll suave.
* **Font Awesome 6 & Google Fonts (Inter / Outfit):** Iconografía y tipografía de estándar internacional.

## 🚀 Despliegue y Visualización Local

Para visualizar el portal en tu entorno local:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/MiguelCarlosRojas/BetaZone.git
   ```
2. Abre la carpeta en tu editor de código o navegador:
   ```bash
   cd BetaZone
   start index.html
   ```
3. O inicia un servidor estático local:
   ```bash
   npx serve .
   ```

El proyecto está listo para ser desplegado automáticamente en **Vercel**, **GitHub Pages** o cualquier proveedor de alojamiento estático.
